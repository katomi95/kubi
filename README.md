# 首を長くして待つ

待ち合わせ相手がなかなか来ないので、首を長くして待つことにした主人公。
頭を動かすと、そのぶん首が伸びる。首だけを伸ばして、待ち人の正面に顔を出す一筆書きパズルです。本人は一歩も動きません。

**プレイ**：https://katomi95.github.io/kubi/

## ルール

- 頭を1マス動かすと、首が1マス伸びる。伸びた首はその場に残る
- 壁や看板、そして**自分の首**は通れない
- **首は縮められない**。やり直すときは首を全部戻して最初から（R キー / 「やりなおす」ボタン、即座に戻ります）
- 待ち人には**正面から**顔を出す（緑の ▶ のマスから）
- 首の長さには上限がある。ステージによっては「ちょうど○マス」首を長くして待たないと、待ったことにならない
- 制限時間なし。Undo なし

## ギミック

| ギミック | 内容 |
|---|---|
| 首の長さ | 上限あり。「ちょうど○マス」のステージも |
| 一方通行 | 標識の矢印の向きにしか入れない |
| 歩道橋 | ここだけは自分の首をまたげる（まっすぐ通るときだけ、縦と横で1回ずつ） |
| 首がこる | 曲がれる回数に上限がある |

## 操作

- **PC**：矢印キー / WASD で頭を動かす、R / Backspace でやりなおす、Esc でステージ選択
- **スマホ**：画面のどこでもスワイプ（指を動かした距離のぶんだけ1マスずつ進む）、頭のとなりのマスをタップ、または右下の十字ボタン
- キーの押しっぱなしは少し待ってからゆっくり進むので、伸ばしすぎにくくしています
- 進めない方向に入力しても何も失わず、理由（「自分の首」「一方通行」など）が表示されます

## ステージ

全10ステージ。クリア状況はブラウザに保存され、タイトルからステージを選べます。
すべてのステージは同梱のソルバー（`solveStage`）で解があることを確認済みで、後半（6〜10）は解が1通りになるよう設計しています。

## 技術メモ

- 単一ファイル（`index.html`）で完結。外部アセット・外部ライブラリ・ビルド一切なし
- 描画は Canvas 2D、効果音・BGM は Web Audio API で合成
- 盤面はマス目、ルール判定は `whyNot()` に集約。首はマスの中心を結んだ折れ線の角を丸め、ゆらぎと「ごくん」と動くこぶを付けて描画
- 歩道橋で首が交差するところは、あとから通った首が手前に見えるよう分けて描画
- PC / スマートフォン両対応、右上の「♪」で音の ON / OFF

ローカルで遊ぶ場合は `index.html` をブラウザで開くだけです。

## GitHub Pages で公開する

`.github/workflows/pages.yml` を同梱しているので、**Settings → Pages → Build and deployment → Source を「GitHub Actions」に設定**すれば、`main` への push ごとに自動デプロイされます。
